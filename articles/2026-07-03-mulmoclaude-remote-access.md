## はじめに

この記事は、**MulmoClaude を使っている方**を対象にしています。

[MulmoClaude](https://github.com/receptron/mulmoclaude) は Claude Code をエンジンに使うローカルアプリで、チャットで話しかけるだけで買い物リストや映画ログなどの「コレクション」を作って管理できます。

このたび**リモートアクセス機能**が追加され、パソコンで作ったコレクションやフィードを、**スマートフォンのブラウザから見たり変更したりできる**ようになりました（v0.9.3 以降）。

中島聡によるアナウンスはこちらです。

https://x.com/snakajima/status/2072819721167311010

本記事では、セットアップ手順と、スマホからできること、スマホ用ビューの作り方を紹介します。

## 1. リモートアクセスでできること

スマホのブラウザから、次のことができます。

| できること | 例 |
|-----------|-----|
| コレクションの閲覧 | 買い物リスト、映画ログ、年間計画などを一覧・詳細表示 |
| データの変更 | 買い物リストの項目をタップしてチェック / チェック解除 |
| ステータスの変更 | タスクの状態をスマホから更新 |
| レコードの削除 | 不要な項目を削除 |
| 写真の送信と登録（次バージョン予定） | レシートを撮って記帳、名刺を撮って住所録に登録、レストランの写真を送って記録 |
| フィードの閲覧 | MulmoClaude に登録した RSS などの情報フィードを確認 |

データの変更と削除は、後述する**スマホ用ビューで許可した項目だけ**ができる仕組みです（許可していないビューは閲覧専用になります）。

外出先で買い物リストをチェックしたり、移動中にタスクの状態を確認したり、といった日常的な使い方ができます。

![スマホから買い物リストをチェック](/images/2026-07-03-mulmoclaude-remote-access/shopping-list.png)

## 2. セットアップ手順

設定は 2 ステップで完了します。

### 2.1. パソコン側：Google アカウントでログイン

MulmoClaude のサイドバーにある**左から 3 つ目のアイコン**（ログインアイコン）をクリックし、Google アカウントでログインします。

![ログインアイコンの場所](/images/2026-07-03-mulmoclaude-remote-access/login-icon.png)

### 2.2. スマホ側：同じ Google アカウントでログイン

スマホのブラウザで以下の URL を開き、パソコン側と**同じ Google アカウント**でログインします。ツールバー右上のサインインアイコンをタップしてください。

![スマホ側のサインイン画面](/images/2026-07-03-mulmoclaude-remote-access/mobile-signin.png)

https://mulmoserver.web.app

ログインが完了すると、自分のコレクションとフィードの一覧が表示されます。

:::message
**前提条件**：パソコン側の MulmoClaude は**起動したままにしておく必要があります**。ノートパソコンがスリープした場合の動作は未検証です。
:::

## 3. スマホ用ビューは Claude にお願いして作る

コレクションの見た目をカスタマイズする Custom View を使っている方も多いと思いますが、スマホ用のビューは**通常の Custom View とは別物**です。スマホで表示するには、**「スマホ用のビュー（Custom Remote View）を作って」と明示的にお願いする**必要があります。

たとえば、チャットで次のように頼みます。

```
買い物リストのコレクションに、スマホ用のビュー（Custom Remote View）を作ってください。
チェックのオン・オフをスマホから変更できるようにしてください。
```

正しく作れると、**パソコン上でスマホサイズの画面（390×844）のプレビュー**が表示されます。ここで確認した見た目が、そのまま実機のスマホでも表示されます。

チェックの変更やステータスの更新など、スマホから**データを変更したい場合はその旨も一緒に伝える**のがポイントです。伝えていない項目はスマホから変更・削除できない（閲覧専用のままになる）安全設計です。

以下は映画コレクションにスマホ用ビューを作った例です。このように、買い物リスト以外のコレクションでも同じ手順でスマホ用ビューを作れます。

![映画コレクションをカード表示するスマホ用ビュー](/images/2026-07-03-mulmoclaude-remote-access/movie-collection.png)

## 4. 次のバージョンで予定：スマホから写真を送ってデータ登録

次のバージョンでは、リモートクライアントから**写真を送ってコレクションにデータを登録する**機能が予定されています。たとえば、レシートの写真を送って記帳したり、名刺の写真を送って住所録に登録したり、お気に入りのレストランを写真付きで記録したりできるようになります。

https://x.com/snakajima/status/2073178203116736534

## 5. セキュリティとプライバシー


「自分のデータがどこを通るのか」が気になる方向けに、押さえておきたいポイントは 2 つです。

- **同じ Google アカウントでログインした本人だけ**がアクセスできます。第三者はアクセスできません
- データは通信のときにサーバーを一時的に経由しますが、**通信が終わるとすぐに消去され、サーバーに残り続けることはない**設計です

## 6. 現時点の制約

- MulmoClaude **v0.9.3 以降**が必要です
- パソコン側の MulmoClaude を**起動したままにしておく必要**があります（スリープ時の動作は未検証）

## まとめ

MulmoClaude のリモートアクセス機能で、パソコンで作ったコレクションをスマホからも使えるようになりました。

- セットアップは**パソコンとスマホで同じ Google アカウントにログインする**
- スマホ用の画面は **Claude に「スマホ用のビュー（Custom Remote View）を作って」とお願いする**
- データはサーバーに残らない設計なので、プライバシー面でも安心です

買い物リストや Todo など、普段パソコンで管理しているコレクションをぜひスマホからも使ってみてください。
